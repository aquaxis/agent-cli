## Execution summary

### Task 1 — Config: `commands_dir`
- Added `commands_dir: String` to `RuntimeConfig` with
  `#[serde(default = "default_commands_dir")]` (`.agent-cli/commands`).
- Added `fn default_commands_dir()`, updated `Default for RuntimeConfig`.
- Documented `commands_dir` in `DEFAULT_CONFIG` `[runtime]`.
- Tests: `runtime_commands_dir_default`, `config_with_custom_commands_dir`,
  `config_without_commands_dir_uses_default`, and an assertion in
  `parse_default_config`.

### Task 2 — `src/custom_commands.rs` (new module)
- `CustomCommand { name, path, content }`.
- `discover(dir)`: scans `*.md`, sorts by name; missing dir → empty vec.
- `expand_template(template, args)`: `$ARGUMENTS` → full arg string; `$1`..`$N`
  → positional args (1-based, missing → empty); remaining `$<digits>` → empty;
  then `expand_at_refs` for `@<path>` (missing/unreadable →
  `[error: cannot read @<path>]`). `expand_path` returns `Result<PathBuf>` and is
  handled for both expansion and read errors (fixed the design snippet that
  would not compile).
- `resolve_dir(s)`: empty → default; expands `~`/env via `config::expand_path`.
- Added `mod custom_commands;` to `src/main.rs`.
- Unit tests: discover (present/missing), `$ARGUMENTS`/`$N`, `@file` (present/
  missing), combined, `resolve_dir` default/override.

### Task 3 — ReplState extension + init
- Added `commands_dir: PathBuf` and `commands: RwLock<Vec<CustomCommand>>` to
  `ReplState`.
- At construction: `resolve_dir(&config.runtime.commands_dir)` +
  `discover(&dir)` → stored in state.
- Updated the `build_state` test helper with the two new fields.

### Task 4 — `CommandResult` refactor
- Added `#[derive(Debug)] enum CommandResult { Continue, SubmittedPrompt, Quit }`.
- Changed `handle_repl_command` return type `bool` → `CommandResult`.
- `"quit" | "exit"` → `Quit`; all other built-in arms fall through to
  `CommandResult::Continue` at the end.
- Updated both call sites (`run_input_loop_raw`, `run_input_loop_line`): on
  `Quit` break/exit; on `SubmittedPrompt` drain `agent_idle_rx` and set
  `PromptState::Pending`; on `Continue` redraw/continue (existing behavior).

### Task 5 — Dispatch + `/commands` + `/reload-commands` + `/help`
- Unknown arm: looks up a custom command by name; on hit, expands the template
  and sends `AgentInput::UserPrompt(prompt)` → returns `SubmittedPrompt`. On
  miss, prints `unknown command: <cmd>` → `Continue`.
- `/commands`: lists custom commands (name, first line, path) or
  `(no custom commands)`.
- `/reload-commands`: re-scans `state.commands_dir`, updates `state.commands`,
  prints count.
- `/help`: added a "Custom commands (.agent-cli/commands):" section listing
  each `/<name>  <first-line>` when non-empty; also documented `/commands` and
  `/reload-commands` in the built-in command list.
- Integration tests: `custom_command_sends_prompt`,
  `builtin_takes_precedence_over_custom`, `unknown_command_no_file_sends_nothing`,
  `reload_commands_picks_up_new_file`, `commands_lists_custom_commands`,
  `custom_command_at_file_expansion`. (Helper `build_state_with_commands` is
  async to avoid blocking inside the runtime.)
