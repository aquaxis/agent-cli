## 3. Deviations from the design (D-1 – D-5)

1. **The command runs in its own process group**, and cancelling signals the
   group. Found by smoke test: `bash -lc "sleep 97"` forks rather than exec'ing,
   so SIGTERM to the shell left the real work orphaned and running. The design
   said "SIGTERM, then SIGKILL" without saying what to signal.
2. **The command's stdin is `/dev/null`.** The terminal is in raw mode and
   belongs to the REPL; a command that read stdin would otherwise compete for the
   user's keystrokes.
3. **The run is held beside `PromptState::Shell`, not inside it.** The `select!`
   arm needs `&mut` on the run while the other arms' guards read the state; this
   mirrors how `approval_rx` is already handled in the same loop.
4. **The runner also stops on `tx.closed()`**, and the raw loop cancels a
   running command on its way out — a smoke test showed a shutdown otherwise left
   the job behind. A `SIGKILL`, or closing the terminal window outright, still
   leaves no chance to clean up; that is documented.
5. **`AgentInput::Context` carries a `source`** as well as the text, so the
   conversation log gets the command and its status without the agent having to
   parse the rendered message back.

- `cargo build` clean. `cargo test`: **452 unit + 2 integration, 0 failed**
  (435 at the v0.14.0 baseline) — 19 new tests, four of which run real commands.
- `cargo clippy --all-targets`: back to exactly the v0.14.0 warning set.
- **PTY smokes** against a real pty, with the live provider for the context
  check:
  - `!echo …` announces and shows the output; the prompt is yellow while the
    line starts with `!`; `!exit 3` reports `[shell] exit 3`; `!` alone prints
    the usage line; `↑` recalls the `!` line.
  - Output streams as it is produced; `Esc` prints `[cancelled]` and returns the
    prompt, and `pgrep` confirms the whole job is gone — as after a timeout, and
    after a `SIGTERM` shutdown while a command was running.
  - `timeout_ms = 800` turns `!sleep 20` into `[shell] timed out after 800 ms`.
  - **End to end**: `!echo MAGENTA-PLATYPUS-4719` followed by "what was the exact
    output?" is answered with the string; with `context = false` it is not.
  - The wheel scrolls back over a 200-line `!seq` output.
  - With `[shell] enabled = false` the session is identical to a **v0.14.0
    binary** built from a worktree at the release tag, and a `!` line is sent to
    the model instead of being run.
