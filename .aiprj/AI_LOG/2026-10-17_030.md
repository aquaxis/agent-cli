## 2. Work plan and execution

1. **Baseline (T-01)**, tree at `5da8bad`: the REPL polls the terminal with
   a fresh `spawn_blocking` task every loop iteration (`event::poll` 50 ms)
   and drains with `poll(0)`+`read()` on the select task itself; a parked
   poll task outlives its iteration, so two or more consumers can be in
   flight; a click during a turn calls `cursor::position()` synchronously
   on the select task. Facts recorded as BL-I1 – BL-I8.
2. **Subagent verifications (T-02)** — three angles:
   - `event-loop-analyst`: crossterm 0.27's single global reader traced in
     the vendored source — a timed `poll` returns `Ok(false)` on a lock
     miss, `read()` locks with no timeout and can block inside the tty
     read; the lag is lock-quantized; the permanent wedge is a blocking
     read parked behind another consumer; no `MutexGuard`-across-await
     anywhere (site-by-site check); indicator repaint contention is
     latency-only.
   - `mouse-mode-analyst`: every mouse-capture writer is correct and
     accounted for (no anonymous child can flip terminal modes); the
     editor buffer is written only by `KeyCode::Char`, so a leak requires
     a desynchronized byte stream; "0.28 rewrote the parser" corrected as
     false.
   - `repro-metrics-analyst`: independently verified the vendored source
     and the upstream tracker (cursor/event mixing acknowledged upstream
     as the race behind position timeouts); delivered pty byte sequences,
     a thread-pile-up diagnostic for the freeze, and an injectable test
     plan.
3. **Aggregate (T-03)**: both symptoms share one root — several consumers
   racing crossterm's single global event reader. Discriminator table
   filled in design §4; repair chosen: one pump thread owns every reader
   call (design §5.1).
4. **Repair (T-04)**: `run_input_pump` + the loop receiving from a bounded
   channel (event order and burst batching preserved); cursor query routed
   to the pump, bounded at 3 s with the previous `Err` fallback; three new
   tests on injectable poll/read/position. Suite **586 + 6, 0 failed**,
   clippy at the 8 pre-existing warnings.
5. **Close-out (T-05)**: scripted pty exercises of the built binary (split
   report bursts + keystroke bursts under busy output; a real turn with
   click bursts and post-turn editing then `/quit`) — session responsive,
   editor clean; the rare race timings themselves could not be forced
   deterministic, stated honestly. Docs: `doc/troubleshooting.md`,
   `doc/architecture.md`; `CHANGELOG.md` `[0.25.0]`; version `0.25.0`.
6. **Commits/release**: implementation `3884d16`, tag `v0.25.0`, GitHub
   release published (release list complete), main pushed (`5da8bad` →
   `3884d16`), working tree clean.
