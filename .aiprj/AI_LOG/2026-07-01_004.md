## Work performed

### 1. Slash command history (FR-17)

- Added `push_history` helper function in `src/app.rs` that appends a line to both
  the in-memory history (`ReplState.history`) and the history file, with
  consecutive-duplicate suppression (matching existing user-prompt logic).
- Modified `handle_repl_command` to record all slash commands (built-in and custom)
  in history before returning `Continue` or `SubmittedPrompt`. `/quit` and `/exit`
  are excluded (they return `Quit` before the history-push point).
- For auto-executed prefix matches, the resolved full command name is recorded
  (e.g. `/hello` not `/he`).
- No change to `ReplState.history` type — remains `RwLock<Vec<String>>`.
  No change to history file format — backward compatible.

### 2. Single-candidate auto-execution (FR-18)

- Modified the `_ =>` (unknown command) arm in `handle_repl_command`:
  - After exact match fails, tries prefix matching on custom commands.
  - If exactly one custom command starts with `cmd`, auto-executes it, printing
    `[auto] /<prefix> → /<resolved>` and returning `SubmittedPrompt`.
  - If multiple custom commands match, prints "ambiguous command: /<prefix> matches:"
    with each candidate and returns `Continue`.
  - If no match at all, prints "unknown command: <cmd>" (existing behavior).
  - Exact matches always take precedence over prefix matches.
  - Built-in commands are not prefix-matched (they require exact spelling per FR-05/FR-07).
