## Actions Taken

### Task 0: Restore a building tree (`src/app.rs`)
- `DisplayState::new(interactive && stdin_is_tty())` → `DisplayState::new(stdin_is_tty())`
  (raw mode is active exactly when stdin is a TTY; `run()` always passes
  `interactive = true`).
- `raw_println(raw_mode, "")` → `raw_println(false, "")` in `run_input_loop_line`
  (the cooked-mode loop is never in raw mode).
- Result: builds; baseline 142 tests pass.

### Tasks 1 & 2: Wrap-aware rendering and multibyte cursor (Defects #1, #2)
- `src/editor.rs`: added `str_display_width(&str) -> usize` as the shared
  column-math source; routed `InputState::display_cursor()` / `display_width()`
  through it.
- `src/app.rs`: added the pure helper
  `layout_cursor(prompt_cols, cursor_cols, total_cols, width) -> (end_row, cursor_row, cursor_col)`,
  which converts display widths into terminal `(row, col)` and accounts for the
  "phantom" last-column wrap (a line that exactly fills the width keeps the
  cursor on the same row).
- `src/app.rs`: replaced the stateless `redraw_prompt` / `redraw_approval_prompt`
  (which used single-row `MoveToColumn(prompt.len() + display_cursor())` and so
  mis-placed the cursor and left stale glyphs once content wrapped) with a
  stateful `PromptRenderer`. It tracks the cursor's physical row offset,
  moves up to the top of the previous block and clears it (multi-row safe),
  reprints prompt + line, then positions the cursor via `layout_cursor`.
  `clear_block()` / `reset()` are reused at every out-of-band transition (agent
  idle, approval arrival, submit, exit cleanup) so wrapped prompts are always
  fully cleared.

### Task 3: Restore Ctrl-C / ESC (Defect #4)
- `handle_key`: Ctrl-C now returns `Eof` on an empty line (raw mode suppresses
  the terminal's SIGINT) and `ClearLine` when text is present — matching the
  `/help` text "Ctrl+D, Ctrl+C, SIGTERM also exit cleanly".
- ESC semantics kept (exit history-browse when browsing, otherwise clear line);
  the `ClearLine` branch now redraws the correct prompt (normal vs approval).

### Task 4: Restore REPL command dispatch (Defect #3)
- **Root cause**: the `break`s for `/quit`/`/exit` (`handle_repl_command`
  returning `false`), `Eof`, and a closed input channel were nested inside the
  inner `while event::poll {…}` event-drain loop. They only stopped draining
  events; the outer input loop kept running, so the app never terminated and
  control keys appeared dead.
- **Fix**: introduced an `exit_loop` flag set at those points; the inner loop
  breaks, then the outer loop breaks after the `select!` when the flag is set.
  `handle_repl_command`'s parsing was already correct and is unchanged.
