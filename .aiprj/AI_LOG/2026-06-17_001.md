## Reported Symptom
入力文字がEnterで消える — the typed line is erased when Enter is pressed instead
of staying visible.

## Root Cause
In raw mode the editor draws an interactive, cursor-positioned render of the
prompt. The submit path in `run_input_loop_raw` cleared that render
(`clear_block`) and printed only a blank newline, so the typed line was never
echoed. In cooked mode the terminal echoed input automatically; raw mode must do
it explicitly.

## Fix
- `src/app.rs`: added `PromptRenderer::finish_line(stdout, prompt, line)`. It
  clears the interactive render (the cursor may be mid-line) and re-emits
  `prompt + line` as a static, fully visible line followed by CR+LF — mirroring a
  normal shell echo.
- Used `finish_line` for all three submit cases in `run_input_loop_raw`: normal
  prompt, slash-command, and approval (`y/N`) response, replacing the previous
  `clear_block` + blank `raw_println` + `reset` sequence.
