## 3. Decisions worth noting

- **The drain window is 10 s and the stop poll 6 s** — constants, not
  config knobs; a knob would have added config surface for a behaviour
  whose observable effect is "stop finishes within seconds either way".
- **Two truthful phrases rather than one**: the queue-skip reply
  (`message not processed: the agent was cancelled`) and the
  interrupted-turn reply (`turn was cancelled; no answer was produced`)
  describe what actually happened; the earlier draft's
  "agent is stopping" wording was dropped because a user-initiated
  `/cancel` in an interactive session reaches the same code and the agent
  is not stopping there.
- **The as-built attribution retained the analysis cycle's mechanism**
  (provider stream cut; send path excluded) without re-litigation: the
  historically-late reports from the analysts arrived between sessions and
  agreed.
