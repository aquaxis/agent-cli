## 3. Findings that shaped the specification

- **agent-cli never redraws what it has printed** and never leaves the main
  screen (BL-01). A pinned prompt with the log moving behind it therefore cannot
  come from "scrolling the terminal": the application has to keep its own copy of
  its output and repaint it.
- **One seam captures everything.** Every REPL message already passes through
  `raw_println` / `raw_print_str` / `raw_eprintln` / `raw_eprint` (BL-02), so the
  transcript is fed there and no writer has to know it exists.
- **The wheel is already swallowed.** Mouse reporting is on during a turn (for
  the clickable reasoning block) and only a left click is handled — every other
  mouse event is discarded (BL-03, BL-04). The feature removes a current
  annoyance as well as adding a mode.

## 4. Key decisions

| Decision | Reason |
|---|---|
| Scroll mode is an **alternate-screen overlay** (AS-03) | Leaving restores the main screen — and the terminal's own scrollback — exactly. Repainting the main screen from a transcript could never be a perfect copy and would push duplicated junk into the scrollback. |
| The transcript records the **styled** bytes (AS-06) | The scrolled view then looks like what was on screen. It forces an SGR-aware wrap (FR-13) and promotes `theme::strip_sgr` out of `#[cfg(test)]`. |
| Output arriving while scrolled does **not** move the view (AS-07) | The reader put the view where it is; being yanked to the bottom mid-read is what makes terminal scrollback frustrating. |
| Mouse reporting becomes the **input loop's** property (FR-15) | It has to be on at the idle prompt too, and the end of a turn must not be able to switch it off underneath the feature. |
| Keyboard scrolling is **out of scope** (AS-01) | The instruction names the mouse; `Up`/`Down` already navigate history, and inventing bindings would go past the instruction. Only `Esc` (leave) and `Enter` (leave + submit) are claimed. |
| `[ui] mouse_scroll` (default `true`) and `[ui] scrollback_lines` (default `2000`) | Claiming the wheel costs the terminal's own selection and wheel-scrollback at the prompt (AS-05); the off switch restores today's behaviour byte for byte, and the cap bounds memory for a long session. |
